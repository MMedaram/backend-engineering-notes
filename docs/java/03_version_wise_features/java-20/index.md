# Java 20

Java 20 is mainly a continuation release that improves features introduced in Java 19.

Detailed notes are intentionally skipped because these features became stable in later Java releases.

We will study them in detail in Java 21 or later.

Features:
- **Scoped Values (Incubator)**
- **Virtual Threads (Second Preview)**
- **Record Patterns (Second Preview)**
- **Pattern Matching for switch (Fourth Preview)**
- **Structured Concurrency (Second Incubator)**
- **Foreign Function & Memory API (Second Preview)**
- **Vector API (Fifth Incubator)**
