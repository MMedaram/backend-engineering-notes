# Java 17 - Features / Enhancements

Java 17 is an LTS release. It standardized sealed classes and interfaces, introduced pattern matching for `switch` as a preview, and included platform, security, and API improvements.

## Java 17 Feature Map

| Area     | Feature                                 | Developer Meaning                                           |
|----------|-----------------------------------------|-------------------------------------------------------------|
| Language | Sealed Classes — Standard               | Explicitly control permitted subtype families               |
| Language | Pattern Matching for `switch` — Preview | Richer type-aware switch dispatch, still preview in Java 17 |
| APIs     | Random generators and `HexFormat`       | Modern random algorithms and byte/text conversion           |

## Preview history

### Sealed Classes — Standard

Java 17 standardized sealed classes after previews in Java 15 and Java 16.
