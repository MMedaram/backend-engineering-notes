# Java 19 Features

> **Release Date:** September 2022
>
> Java 19 is a **non-LTS (Short-Term Support)** release.
>
> This release mainly focuses on **Project Loom**, **Pattern Matching**, and **Preview/Incubator APIs**. Most features introduced here became stable in later Java versions (especially Java 21).



This release mainly introduced preview and incubator features.

Detailed notes are intentionally skipped because these features became stable in later Java releases.

We will study them in detail in Java 21 or later.

Features:
- **Virtual Threads (Preview)**
- **Structured Concurrency (Incubator)**
- **Record Patterns (Preview)**
- **Pattern Matching for switch (Third Preview)**
- **Foreign Function & Memory API (Preview)**
- **Vector API (Fourth Incubator)**
