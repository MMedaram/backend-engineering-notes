# Java 18 Features

> **Release Date:** March 2022
>
> Java 18 is a **non-LTS (Short-Term Support)** release.
>
> It mainly focuses on **developer productivity, platform improvements, standardization, and preview/incubator features** rather than introducing major language changes.

---

After completing Java 18, we should understand:

- Why UTF-8 became the default encoding
- How to use the built-in Simple Web Server
- New Javadoc code snippets
- Why finalization is being removed
- Pattern Matching for `switch` (Second Preview)
- Basic awareness of Vector API
- Basic awareness of Foreign Function & Memory API
- Reflection improvements
- Custom DNS resolution using the new SPI
